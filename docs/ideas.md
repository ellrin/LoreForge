LoreForge 是下班時間的創作：挑好玩、酷、合作者個性的東西。

## 1. 自己的小模型（訓練實驗室）
- 在本機（Apple Silicon，MLX）用 LoRA 微調一個小模型：只用作者自己的文字（論文、簡報、潤飾按讚的句子）；指引的例句不算。
- 「訓練實驗室」介面：loss 曲線即時畫（lore-plot）、同一段話比較 base 與微調後的版本、漸進式訓練。
- 練好的模型接 lore-llm（本機引擎），L-Paper「我的風格」可以改用它。資料與權重放 `LOCAL_LLM_HOME`／私人資料夾，不進 repo。

## 2. 會動的論文
- L-Reader 的方程式按一下變成互動圖：參數是滑桿、曲線即時變（lore-notation 的符號、lore-plot、mathsvg）。
- 寫書時可以收進書裡（靜態圖＋互動版）。

## 4. LoL 賽後分析師

## 6. 知識庫回饋 Lore 系列（2026-11-14 記下）
原則：**畫面不能變亂**。每一項都是可以關掉的層（預設關或只在需要時出現），不常駐在畫面上。
- **可能是同一張卡**：標題相近、摘要語意很像、別名重疊（例：Talocrural 與 Talocrural joint），列成清單，一鍵合併。
- **補上漏掉的連結**：兩張卡內文互相提到、或出自同一篇論文卻沒有 `[[連結]]`，建議補上（圖譜的線現在只來自手寫連結）。
- **跨領域的橋**：同時連著兩群卡的概念（例：Dice 在分割與模糊損失之間），可回饋 L-Paper 的新論文發想。
- **讀論文時標出還不懂的前置知識**：L-Reader 打開論文時對照知識庫，標出不熟的卡、知識庫沒有的概念（接「寫書」）。作者很想要，但一定要有開關。
- **用詞一致**：L-Slide／L-Paper 寫術語時用卡片的標準名稱與別名，連到 lore-notation 的符號。

## 7. L-Reader 同時開多篇 PDF（2026-11-24 討論，還不做）

**現況**：桌面程式只有一個視窗。從 Finder 開第二個 PDF 時，新檔匯入書庫後同一個視窗換去顯示它，所以原本那篇看起來「跳掉」。原本那篇還在書庫，筆記也在；有還沒存成 PDF 的筆記時離開會問一次。

**需求**：平常用分頁切換，需要時能拉開成兩個視窗並排對照。

**地端模型會不會開兩個**：不會。整台電腦只有一個地端模型程序（`docs/local-models.md`），多個視窗仍是同一個 App、登記一次。兩個視窗同時叫模型時排隊；兩邊要不同模型時還要等切換。會隨視窗數增加的是畫 PDF 頁面的記憶體，和模型無關。

**傾向的做法：macOS 內建的視窗分頁**（Finder、Safari 那一套）。
- 每篇 PDF 一個視窗，系統把它們收成分頁；分頁往外拖就是獨立視窗，拖回去或「合併所有視窗」又變回分頁；⌘⇧] ⌘⇧[ 切換。分頁和拉開對照是同一個機制。
- L-Reader 用的是系統標準視窗框，Tauri 2 有 `tabbing_identifier`（在 tauri 2.12.5 和 tao 0.37.2 的原始碼裡確認過存在，還沒實際試）。
- 伺服器本來就是每篇論文分開處理，要改的是桌面視窗那一層：`apps/desktop/src/main.rs` 有 7 處寫死 `"main"` 視窗，`open_file` 是叫主視窗換網址。

**代價**
1. 分頁列是系統的樣子，不跟 Lore 的主題配色。
2. 每個分頁都是完整載入的頁面，開十篇就是十份記憶體。
3. 假設「現在開著的只有一篇」的地方要改成「最前面那個分頁」：關閉前檢查未存的筆記（`open_paper` / `confirm_close`）、選單的列印和匯出、做成簡報、交給 L-Echo、加入知識庫。

**沒選的做法**
- 自己在頁面裡畫分頁：配色能跟主題，背景分頁可以不載入；但拉開對照仍要多視窗，等於兩件都做，工作量約兩到三倍。
- 同一個視窗左右分割顯示兩篇：頁面程式整個以「一篇」為前提（`web/app.js` 約 90 處用到目前這一篇），改動太大。
- 維持單視窗加「最近開過」切換鍵：改動最小，但同時只看得到一篇。

**動工前要作者決定**
1. 系統樣式的分頁列可以接受嗎？（決定走系統分頁還是自己畫）
2. 從 Finder 開新的 PDF：在目前視窗加一個分頁（預設），還是開新視窗？
3. 再開一次已經開著的那篇：跳到原本那個分頁（預設），還是再開一個？
4. 通常同時開幾篇？常超過五六篇的話要處理記憶體。
5. L-Echo 只有一個，跟著最後反白的那個分頁走（和現在「新的反白取代舊的」一致），可以嗎？

L-Paper 和 L-Slide 也是單視窗，之後想多開可以用同一套做法。

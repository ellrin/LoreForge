# 之後想玩的點子（2026-11-13 記下，還不做）

LoreForge 是下班時間的創作：挑好玩、酷、合作者個性的東西。

## 1. 自己的小模型（訓練實驗室）
- 在本機（Apple Silicon，MLX）用 LoRA 微調一個小模型：只用作者自己的文字（論文、簡報、潤飾按讚的句子）；指引的例句不算。
- 「訓練實驗室」介面：loss 曲線即時畫（lore-plot）、同一段話比較 base 與微調後的版本、漸進式訓練。
- 練好的模型接 lore-llm（本機引擎），PaperComposer「我的風格」可以改用它。資料與權重放 `LOCAL_LLM_HOME`／私人資料夾，不進 repo。

## 2. 會動的論文
- LoreReader 的方程式按一下變成互動圖：參數是滑桿、曲線即時變（lore-notation 的符號、lore-plot、mathsvg）。
- 寫書時可以收進書裡（靜態圖＋互動版）。

## 4. LoL 賽後分析師
- 一場結束後抓數據（Riot API，金鑰放 keychain），lore-plot 畫經濟、視野、團戰時間線。
- LoreEcho 語音教練聊這場（本機或雲端模型），資料留在本機。

## 5. SlideComposer 手勢模式（簡報時）——試過、放棄（2026-11-13）
- **結果**：2026-11-13 做出來、作者實機試過後放棄：「沒用，手好酸」——簡報時一直舉手對著鏡頭，手臂很快就累。程式（lore-gesture、handmode.js、相機權限）全部移除；之前的版本只留在作者自己的備份，不在 repo 裡。
- **留下來的**：一般模式的**選頁**（簡報者畫面的四格按鈕＋G，所有頁的縮圖＋頁碼、目前頁、隱藏頁也能選；觀眾畫面選定才換頁）。
- 當時的構想（記錄用）：筆電鏡頭看講者的手（Apple Vision，只在本機）；食指＝雷射、停留觸發的半透明按鈕（換頁、畫筆、橡皮擦、清除、選頁）、捏住落筆、狗手勢分段放大、揮手換頁、發光輪廓的選頁。
- 如果以後再想：不要靠一直舉手的操作；要先想不累的輸入方式（遙控器、手機、語音）。
